The configuration file does not travel between computers. What changes is the monitor setup: the user's
laptop is docked at different places with different monitors (stated 2026-10-31).

**Why:** I justified keeping the window placement out of the config with "the config travels between
computers"; the user corrected that.

**How to apply:** for anything tied to screens (window positions, RDP monitor choice), expect monitors to
appear and disappear between runs and while the app is in the tray; don't argue from config sharing.
